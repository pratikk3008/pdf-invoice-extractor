# Example Outputs

Sample outputs produced after running `python main.py` or `POST /load/samples`.

| File | Description |
|------|-------------|
| [summary.example.json](./summary.example.json) | Aggregated invoice summary |
| [metrics.example.json](./metrics.example.json) | Runtime processing metrics |

To regenerate live outputs locally:

```bash
python main.py --verbose
```

Results are written to the `output/` directory.
